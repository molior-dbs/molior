### UR100 WebUI Functions

- URB2
- category: graphical-user-interface

The following actions shall be available on the WebUI

- repository mirror creation
- base mirror creation
- Software project creation
- Software project version creation and modification
- Software project version filtering
- Software project version sorting
- User / role management

**Acceptance criteria:** Listed functions are available on the WebUI and
actions are started by pressing the corresponding buttons
