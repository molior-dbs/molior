
### UR001 Package Deployment

- URB0
- category: functional-requirement

The Debian toolchain shall be able to deploy the Debian packages of UR000 or UR018 into the corresponding _debian repositories_ (as defined in the _Software Project_) upon successfully building the debian packages (includes _short tests_)

**Acceptance criteria:** The test package is available on the specified
test package repositories, accessible via HTTP
