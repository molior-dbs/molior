### UR018 Package CI Building

- URB0
- category: functional-requirement

The Debian toolchain shall be able to build the latest version of the source code repository (git) upon check-in. The source code is built on top of one or more specified debian repositories (as defined in the _Software Project_) into one or more Debian packages (based on the definition in the source code).

**Acceptance criteria:** The test package is available after a check-in
into the source code repository
