### UR000 Package Building

- URB0
- category: functional-requirement

The Debian toolchain shall be able to build a specific tag of the source code repository (git) upon tag creation. The source code is built on top of one or more specified debian repositories (as defined in the _Software Project_) into one or more Debian packages (based on the definition in the source code).

The following source code systems and functions are supported

- Git repos
- Git repos with submodules
- Git repos with lfs

The package building is supported for Intel and ARM architectures according to the definition in the debian toolchain configuration.

**Acceptance criteria:** the test package is available for Intel and ARM
architecture after tagging the source code repository
