### UR101 Dashboard

- URB2
- category: graphical-user-interface

The Debian toolchain shall provide a dashboard. The content is the _Software Project_ version configuration items and the status of package building pipeline. The information shall be provided to the user according to his role, and be able to be filtered by:

1. _Software Project_ name
2. _Software Project_ version

**Acceptance criteria:** Project configuration items of the test
Software Project are shown in the WebUI, pipeline state information are
available per project version.
