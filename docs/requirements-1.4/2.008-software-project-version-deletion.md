### UR008 Software Project Version Deletion

- URB2
- category: functional-requirement

The Debian toolchain shall be able to delete any version of a _Software Project_. This includes the following steps:

- the packages of the version get removed of the _Debian repository_
- the version of the _Software Project_ will be deleted of the software project version list


**Acceptance criteria:** The instance of a Software Project is
no longer available on the Debian toolchain database and not accessible anymore through the
web interface
