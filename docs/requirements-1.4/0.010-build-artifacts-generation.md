### UR010 Build Artifacts Generation

- URB0
- category: functional-requirement

The Debian toolchain shall generate the build artifacts of a particular release of a _Software Project_.

- Binaries
- Binaries with debug symbols (depending on the package definition)
- Development packages (depending on the package definition)
- Sources (depending on the package definition)
- build environment information

**Acceptance criteria:** The listed artifacts are available within the
test package
