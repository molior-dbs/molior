### UR300 Role Based Access

- URB2
- category: security

The Debian toolchain shall provide role based access for users

- Available user roles:
  - SoftwareProjectMember (Can see the build progress of the
    assigned _Software Project_)
  - SoftwareProjectOwner (Can manage _Software Project_ membership
    and versions, includes project member)
  - ToolChainAdministrator (Can create _Software Projects_, has
    all rights on all Projects)
- Users can be assigned to one role per _Software Project_.
- Access rights are granted by the administrator or the project
  owner.
- One user is selected as owner on creation of the _Software Project_

**Acceptance criteria:** A test project can only be created by the
ToolChainAdministrator, SoftwareProjectMember can only be added by
SoftwareProjectOwner
