### UR007 Software Project Version Creation

- URB2
- category: functional-requirement

The Debian toolchain shall be able to create/clone/overlay a new version of a _Software Project_. This includes the following steps:

- set a version name
- select at least one base mirror and architecture which the software project is based on
- create a corresponding debian repository
- add the address of the corresponding source code repository
- specify dependencies to other _Software Project_ versions

**Acceptance criteria:** A named instance of a Software Project is
available on the Debian toolchain database and accessible through the
web interface, depending repositories and Software Projects are visible
on the web interface, corresponding package repository is available and
accessible through HTTP
